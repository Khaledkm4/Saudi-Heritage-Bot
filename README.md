# ⛺ Al-Ma'zib | Saudi Heritage Educational Platform
**Al-Ma'zib** is an interactive platform and smart AI-powered tour guide designed to revive Saudi heritage and highlight the culture, history, geography, and authenticity of various regions across Saudi Arabia.
## ✨ Key Features
* **🗺️ Interactive Heritage Map:** Explore the Kingdom's regions through an interactive map that allows users to click on any region to learn about its authentic heritage.
* **💬 AI-Powered Chat (Ask Al-Ma'zib):** A smart chat interface powered by advanced language models to provide accurate and well-formatted tourism and historical answers.
* **📚 Comprehensive Cultural Encyclopedia:** Customized details for each region, including traditional foods, handicrafts, and traditional clothing, accompanied by integrated FAQs.
* **🎥 Embedded Video Guides:** In-app video players providing visual explanations and tutorials, such as detailed video guides on traditional handicrafts.
* **🌓 Flexible UI (Dark/Light Mode):** Full support for dark and light modes to ensure user comfort and a unique visual experience.

## 🛠️ Tech Stack
| Technology | Usage |
| :--- | :--- |
| **Python / Flask** | Backend development and routing |
| **Google Gemini API** | AI engine for generating tourism and historical text |
| **HTML / CSS / JavaScript** | Interactive frontend user interface |
| **Leaflet.js & Esri Maps** | Interactive mapping without paid API keys |
| **python-dotenv** | Environment variable and API key management |
## ⚙️ Installation & Setup
1. **Clone the repository:**
`git clone https://github.com/your-username/Saudi_Heritage_Bot.git`
`cd Saudi_Heritage_Bot`
2. **Install dependencies:**
`pip install flask google-genai python-dotenv`
3. **Environment Variables:**
Create a `.env` file in the root directory and add your API key:
`GOOGLE_API_KEY="AIza_YOUR_API_KEY_HERE"`
4. **Run the application:**
`python app.py`
